#How to Run the file (Windows OS)

1. Download the Java file (FilfillmentOptimizerLex.java)
2. Open command prompt and go to the location of the downloaded file
3. Check if Java exists by running `javac -version`
4. If not available please install Java
5. If available run the command `javac FilfillmentOptimizerLex.java`
6. Once compiling is done, run the command `java FilfillmentOptimizerLex.java`, you should see the response.
